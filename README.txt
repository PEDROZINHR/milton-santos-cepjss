# Site — Milton Santos | CEPJSS

## Como abrir no Visual Studio Code
1. Extraia o arquivo ZIP.
2. Abra o Visual Studio Code.
3. Clique em **File > Open Folder** (Arquivo > Abrir Pasta).
4. Selecione a pasta `site_milton_santos`.
5. Abra `index.html` no navegador. Se tiver a extensão **Live Server**, clique com o botão direito em `index.html` e escolha **Open with Live Server**.

## Arquivos
- `index.html`: conteúdo e estrutura do site.
- `style.css`: visual, cores e responsividade.
- `script.js`: menu para celular.
- `assets/`: foto enviada pelo grupo.

A fotografia de 1994 é carregada da Wikimedia Commons e precisa de internet para aparecer. O crédito e a licença estão indicados no rodapé do site.
